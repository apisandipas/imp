imp docs

imp is a text editor with Vim's keys and Emacs's depth. Almost all of it is written in Scheme, and you can change any part of it while it runs.

New to imp? Start with the guides, in order:

  1. Install and first steps: get imp running and learn your way around.
  2. Configuring init.scm: options, keys, commands, hooks and themes.
  3. Packages: the extras that come with imp, and writing your own.
  4. Coming from Emacs or Vim: what carries over and what's different.

The reference below has a page for each part of imp. Each page starts with what it can't do yet, so you know before you read on.

imp is in alpha. It's usable day to day, but expect rough edges and changes. Bug reports are welcome.
